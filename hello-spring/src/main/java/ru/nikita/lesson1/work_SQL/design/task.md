### Основное задание

Спроектируй схему БД для системы управления проектами:

**Требования:**
- Пользователи (с ролями: admin, manager, developer)
- Проекты (название, описание, статус, даты)
- Задачи (привязаны к проекту, назначены на пользователя)
- Комментарии к задачам
- История изменений статуса задачи

**Создай:**
1. SQL-скрипт создания таблиц
2. Внешние ключи с правильным ON DELETE
3. Индексы для типичных запросов
4. CHECK constraints для статусов

**Критерии:**
- [ ] Схема в 3NF
- [ ] Все связи имеют FK
- [ ] Есть индексы
- [ ] Есть constraints

### ⭐ Задание со звёздочкой

Добавь:
- Метки времени (time tracking) для задач
- Теги для проектов (M:N)
- Аудит: кто и когда изменил задачу
